### About Me

I'm a robotics enthusiast from **FRC Team 11019 Xplore**, based in Shanghai. I build things at the intersection of hardware and software — from CAD-driven robot design to AI-powered dev tools. When I'm not wrenching on robots, I'm crafting tools that make building faster and more fun.

- 🤖 FRC robotics — CAD (SolidWorks), strategy scouting, tech binders
- 🧠 AI dev tools — [**SLATE**](https://github.com/CaryWang1234/SLATE), an AI agent for structured ideation
- 🛠️ Utility builders — HyperBinder, pyparser, Exam Paper Generator
- 🌐 Web & full-stack — JS/Python, FastAPI, vanilla frontends
